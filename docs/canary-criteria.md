# 카나리 판단 기준

새 버전에 요청 일부만 보내 볼 때, 다음 단계로 넘어갈지 되돌릴지를 미리 정해 둔다. 숫자로 판단할 수 있게 적는다.

| 단계 | 머무는 시간 | 다음 단계로 가는 조건 | 되돌리는 조건 |
| --- | --- | --- | --- |
| 10% | | (예: 실패 응답 0건, 응답 시간이 이전 버전보다 크게 늘지 않음) | |
| 50% | | | |
| 100% | | | |

- 어디서 확인하는가: 요청 확인 스크립트(`scripts/watch_requests.py`)의 리비전별 응답 수, Cloud Run 콘솔 측정항목의 리비전별 요청 수·오류·지연 시간
- 답변 품질 같은 AI 기준: 관측 도구를 붙인 뒤 이 표에 추가한다.
